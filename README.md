## 📖 项目介绍

1.TitanCore 坚持完全开源、代码干净、架构透明、零黑盒的理念，完全公开开源。

2.前端 UI & C++ 底层注入，没有任何后台恶意代码，软件本身已经过国家备案审核以及微软商店审核。

3.支持全单机离线模式，即使断开网络，也可以管理本地游戏库与启动增强功能。
